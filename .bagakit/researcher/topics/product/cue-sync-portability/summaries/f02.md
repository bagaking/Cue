# Apple Document Packages summary

## What This Is

- source id: `f02`

## Why It Matters

Defines a package as a directory presented as one document.

## Borrow
- Use a cue package as the one mutable workspace boundary.

## Avoid
- Do not treat a cue.md file as an equivalent mutable workspace.

## Bagakit Implication
- Cue and cue.md should have non-overlapping roles.
