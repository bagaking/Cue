# Apple NSFileCoordinator package semantics summary

## What This Is

- source id: `f06`

## Why It Matters

Cue must read document bytes and revision in one package accessor and recheck the live revision inside the coordinated publish accessor.

## Borrow
- Coordinate the package URL itself, always use the accessor URL, and keep one synchronous accessor around the final CAS plus replacement.

## Avoid
- Do not mistake forReplacing notification semantics for the storage transaction or rely on coordination without a semantic revision check.

## Bagakit Implication
- Cue selects options [] for same-document package mutation and performs its own final CAS; this is a Cue design inference, not an Apple atomicity promise.
