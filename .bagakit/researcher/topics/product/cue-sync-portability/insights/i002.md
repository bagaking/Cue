# Independent records reduce sync contention only when global metadata stops being authoritative

## Insight

Per-item Markdown is a useful merge unit, but a manifest listing every item recreates one global conflict hotspot and can orphan valid records.

## Why It Matters

The package architecture direction is sound only after membership becomes directory-derived and conflict-safe.

## Borrow
- Keep stable item identity and independently mergeable files.

## Avoid
- Avoid an authoritative global member list, dense reorder rewrites and wall-clock deletion.
